# kuralovsa/course

(Основной README — обновлённая версия с секцией по внешним PoC)

Этот репозиторий содержит материалы и примеры по исследованию уязвимостей, методологиям и инструментам для тестирования безопасности. Основной упор — исследования в области обработки изображений, WebKit и iMessage/сообщений в iOS.

Важно: многие материалы репозитория — PoC и вспомогательные инструменты. Никогда не запускайте PoC в продуктивной среде. Всегда используйте снапшоты, виртуальные машины или контейнеры.

Внешние PoC и интеграция

Мы периодически интегрируем внешние PoC в раздел `research/` как обзорные материалы и инструкции по безопасному воспроизведению. Например, интеграция CVE-2021-30860: см. `research/CVE-2021-30860/README.md`, который ссылается на оригинальный PoC: https://github.com/jeffssh/CVE-2021-30860

Структура репозитория

- `research/` — детальные исследования, PoC и runbook'ы.
- `patches/` — заметки и патчи для тестирования и бэктрекинга.
- `scripts/` — вспомогательные скрипты для сборки и запуска уязвимых окружений.

Если вам нужна помощь с воспроизведением или переносом PoC, откройте issue или свяжитесь со мной.
