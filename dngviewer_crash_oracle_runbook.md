# DNGViewer — Crash Oracle Runbook (переработано)

Цель

Документ служит runbook'ом для работы с crash-oracle подходом при анализе DNG/DNGViewer-уязвимостей. Приведён в единый шаблон для воспроизводимости и безопасности.

1) Краткое описание

Runbook описывает процесс использования автоматизированного оркестратора тестов и crash-oracle для выявления уязвимостей в компоненте DNGViewer.

2) Окружение и требования

- macOS или Linux с установленными инструментами отладки (lldb/gdb), Python 3.x, необходимые библиотеки.
- Рекомендуется использовать snapshot/VM и отключённую сеть.

3) Подготовка

- Развернуть тестовую систему и убедиться, что все зависимости установлены.
- Подготовить набор контрольных и payload-файлов (например, `make_dng_payload.py`).

4) Шаги воспроизведения и тестирования

- Разместите контролируемые входные файлы в директории тестов.
- Запустите harness/оркестратор для подачи файлов в исследуемый бинари (см. `run_cassowary_harness.sh` и `cassowary_harness.js`).
- Наблюдайте за крешами, собирайте логи и core dump, фильтруйте шум через crash-oracle правила.

5) Анализ и артефакты

- Сохраняйте логи, снапшоты процесса и минимальные файлы, приводящие к крешу.
- Фиксируйте версии ОС и сборки бинара.

6) Митигации

- Предлагайте фиксы и патчи через `patches/` с указанием тестов, подтверждающих исправление.

7) Примечания безопасности

- Во всём процессе подчёркивать использование изолированных сред и снапшотов.
- При публикации результатов указывать авторство исходных PoC.
